# ML Model Registry — perception signals (owner: Sohon)

Weights are **never committed to git**. They live in the private consolidated HF repo
`Shota2811/ps26094-signals` (upload: `services/scoring/training/push_to_hub.py`) and are bind-mounted
into the scoring container as `/models` (`docker-compose.yml`). Metrics below are regenerated by
`PYTHONPATH=. python evals/eval_signals.py` into [`artifacts/signal_eval.json`](../artifacts/signal_eval.json).

> All text corpora are hand-written / synthetic prototypes (no public Indian caste-violence distress
> corpus exists) and the voice corpus is **acted** English speech. These are honest held-out numbers on
> that data, not production validation. Scores are model scores, not clinical or forensic probabilities.

## distress_v3 — sentiment / distress level

| Field | Value |
| :--- | :--- |
| Task | 3-class text classification of expressed distress |
| Labels | `LOW` (0) · `MODERATE` (1) · `HIGH` (2); API also returns `sentiment_score` = expected level / 2 ∈ [0,1] |
| Base model | `google/muril-base-cased` (MuRIL, multilingual EN + Indic + code-mixed) |
| Dataset | distress V3: 480 rows EN + Hinglish (270 hand-written, 210 templated), leak-aware split 353/73/54 — templated groups never reach the test set, test is hand-written only |
| Training | `services/scoring/training/train_sentiment.py` (lr 3e-5, batch 8, 12 epochs max, max_len 64, 10 % warm-up, early stop on macro-F1, seed 42) |
| Held-out test | accuracy **0.907**, macro-F1 **0.907**; per-class F1 LOW 0.895 · MODERATE 0.882 · HIGH 0.944 |
| Adversarial challenge (37 rows) | accuracy **0.919**, macro-F1 0.917 |
| Calibration | temperature scaling, **T = 0.127** (fitted on 73 val rows); test ECE **0.451 → 0.084**, NLL 0.833 → 0.440 |
| Local artifact | `models/distress_v3/` (`model.safetensors`, `calibration.json`, `metrics.json`) |
| Hugging Face | `Shota2811/ps26094-signals` → `distress_v3/` (canonical, private) · public mirror `Shota2811/HackHeritage26-distress-v3` |
| Status | **current** — served |

Known weakness: MODERATE vs LOW when a sentence ends on a coping clause ("…but I'm managing").

## threat_contrastive_v1 — threat / intimidation (served)

| Field | Value |
| :--- | :--- |
| Task | binary text classification: coercion / intimidation vs everything else |
| Labels | `NOT_THREAT` (0) · `THREAT` (1); API returns `threat_flag` (prob ≥ 0.5) + calibrated `prob` |
| Base model | `google/muril-base-cased` |
| Objective | cross-entropy **+ supervised contrastive loss on the [CLS] embedding** — separates "I'm sad" from "I'm being threatened into silence" in embedding space, not only at the logit |
| Dataset | threat V7: 520 rows (265 threat / 255 non-threat), 329 EN + 191 Hinglish, synthetic V5 + V6 generators, includes hard negatives (negation, fear-without-threat, benign advice, third-party reports) |
| Training | `services/scoring/training/train_threat.py --objective contrastive` (lr 2e-5, batch 8, max_len 128, seed 42) |
| Held-out test (78) | accuracy **0.974**, precision 0.974, recall 0.974, F1 **0.974**, ROC-AUC **0.998** |
| Adversarial challenge (51) | accuracy **0.980**, F1 0.980, ROC-AUC 0.995 |
| Hard negatives (22 of test) | accuracy **0.955**, false-positive rate 0.045 |
| Per language (test) | English 0.957 · Hinglish 1.000 |
| Calibration | temperature scaling, **T = 0.109** (78 val rows); test ECE **0.368 → 0.013**, NLL 0.501 → 0.089 |
| Local artifact | `models/threat_contrastive_v1/` |
| Hugging Face | `Shota2811/ps26094-signals` → `threat_contrastive_v1/` (canonical, private) |
| Status | **current** — served (preferred over `threat_v7`) |

Known weakness: one ambiguous false positive ("please think carefully before getting involved") and one
soft financial-coercion miss ("someone told me my income was at risk").

## threat_v7 — threat / intimidation (frozen baseline)

| Field | Value |
| :--- | :--- |
| Task / labels / base model | identical to `threat_contrastive_v1` |
| Objective | plain cross-entropy (the V7 recipe) |
| Dataset | the same threat V7 corpus and splits |
| Held-out test (78) | accuracy 0.962, precision **1.000**, recall 0.923, F1 0.960, ROC-AUC 0.997 |
| Adversarial challenge (51) | accuracy 0.980 |
| Calibration | temperature scaling, T = 0.140; test ECE 0.318 → 0.025 |
| Local artifact | `models/threat_v7/` |
| Hugging Face | `Shota2811/ps26094-signals` → `threat_v7/` · public mirror `Shota2811/HackHeritage26-threat-v7` |
| Status | **frozen baseline** — kept for comparison, never deleted; used automatically if the contrastive checkpoint is absent |

Why it was superseded: it missed soft witness intimidation with no explicit consequence
("they asked me to forget what I had seen"); the contrastive model scores 7/7 on that category.
It keeps a zero false-positive record on the test set, which is why it stays as the conservative fallback.

## voice_stress_ravdess — acoustic stress

| Field | Value |
| :--- | :--- |
| Task | binary acoustic stress from a short clip |
| Labels | `NOT_STRESSED` (0: neutral, calm, happy) · `STRESSED` (1: sad, angry, fearful) |
| Pipeline | librosa 89-dim features (MFCC + Δ, F0/pitch incl. relative `f0_cv`, jitter, shimmer, RMS, ZCR, spectral, pause ratio, onset rate) → LightGBM |
| Inference | **numpy tree evaluator** over the dumped LightGBM trees (`app/tree_eval.py`) — LightGBM is never imported next to torch (duplicate OpenMP runtimes segfault on macOS); training asserts the evaluator reproduces `predict_proba` bit-exactly before saving |
| Dataset | RAVDESS speech (Zenodo 1188976, CC BY-NC-SA): 1,056 clips, 24 actors; disgust/surprised dropped as ambiguous arousal |
| Training | `services/scoring/training/train_voice.py --source ravdess` (600 trees max, lr 0.03, 15 leaves, balanced classes, early stop on a by-actor val split, seed 42) |
| Speaker-independent CV | GroupKFold(6) **by actor, every actor held out exactly once**: accuracy **0.752**, balanced accuracy 0.748 ± 0.040, precision 0.763, recall 0.792, F1 **0.777**, ROC-AUC **0.824** |
| Per emotion (CV) | angry 0.90 · fearful 0.84 · neutral 0.81 · calm 0.78 · sad 0.63 · happy 0.58 |
| Fixed by-actor split | reported in `artifacts/signal_eval.json`; the served model was re-fit on all 24 actors, so that split is in-sample — the CV row above is the honest number |
| Calibration | none — raw LightGBM probabilities (no temperature fitted for this signal) |
| Local artifact | `models/voice_stress_ravdess.joblib` (+ `voice_metrics_ravdess.json`, `voice_feature_order_ravdess.json`) |
| Hugging Face | `Shota2811/ps26094-signals` (canonical, private) · public mirror `Shota2811/HackHeritage26-voice-stress-v1` |
| Status | **current** — served |

Caveat to state out loud: RAVDESS is **acted** English speech. This is a prototype acoustic stress
signal, not validated real-world victim stress detection. Indian-accent / phone-line adaptation is the
known domain gap; `train_voice.py --extra-features-csv` is the hook for adaptation rows.
